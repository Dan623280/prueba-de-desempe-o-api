# SkillHub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build the complete SkillHub assessment API and participant client.
**Architecture:** Domain -> Application -> Infrastructure -> API. Controllers delegate to interfaces; PostgreSQL persists Identity and workshop data.
**Tech Stack:** .NET 10, EF Core 10, Npgsql, Identity, JWT, Swashbuckle, ClosedXML, PDFsharp.
**Spec:** docs/superpowers/specs/2026-10-27-skillhub-design.md

## Global Constraints
- English classes, methods, comments, project names and README.
- PostgreSQL in the existing Docker container.
- DependencyInjection.cs in every layer; services and repositories behind application interfaces.
- All protected routes require JWT and enforce actor ownership or Employee role.

## Review Focus
- Simultaneous enrollment requests cannot overbook or double book a participant.
- Exact cancellation boundary and adjacent time intervals behave consistently.
- Malformed workbooks return a clear 400; row failures do not roll back successful rows.
- Participants cannot obtain another participant's enrollments or certificates.
- Seeding is idempotent and never imports pending enrollments automatically.
